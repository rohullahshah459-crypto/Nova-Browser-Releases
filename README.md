# Nova Browser

**Official public download hub for Nova Browser.**

Nova Browser is a modern Windows desktop browser. The application source code is maintained privately; this public repository is used only for official releases, downloads, release notes, and public information.

## Download

The latest Windows installer and portable build will be published under **Releases** on this repository.

- **Installer:** Recommended for most Windows users.
- **Portable:** Run Nova Browser without a normal installation.

## Current version

**Nova Browser v1.0.0**

## Windows notice

Nova Browser is currently distributed without a commercial code-signing certificate. Windows SmartScreen may show an **Unknown publisher** warning on first install. Only download Nova Browser from this official repository.

## Privacy and source code

The production source code is private and is not distributed from this repository.

## Support

For release problems or installation issues, use the Issues section of this repository.
